4 keer 3

Vind de 4 groepen van 3 woorden. 1 woord zit in alle vier de groepen.

Puzzel

Kies drie woorden die bij elkaar horen.

Opgelost

Geinspireerd op 4 × 3 van Hank Green

Archief

Score

Elke winst begint op 100 punten. Je verliest punten voor fouten, krijgt punten voor flair, en daarna komt je dagreeks erbij. Een foutloze run kan strak op 200 uitkomen, plus je reeks.

Fouten

  • Elke fout: -15
  • Een fout met nog maar twee groepen over: -30

Bonussen

  • Hub Eerst: begin elke gok met het gedeelde woord: +20
  • Hub Midden: zet het gedeelde woord steeds als tweede: +20
  • Blauw Eerst: los de blauwe groep als eerste op: +5
  • Paars Eerst: los de paarse groep als eerste op: +15
  • Omgekeerde Regenboog: paars → blauw → groen → geel: +30
  • Onder 90 seconden: +30
  • Dagreeks: +1 per dag in je huidige reeks

Alleen voor opscheppen

  • 🌈 Regenboog: geel → groen → blauw → paars
  • 🎾 Grellow: paars → blauw → geel → groen
  • 🦚 Grue: paars → groen → blauw → geel
  • 😤 God Damnit!: foutloos met Hub Eerst, maar alleen verpest door groen↔geel of groen↔blauw

Hoogste eer

  • Perfect Game: 0 fouten + Hub Eerst + Omgekeerde Regenboog = 200 voor je reeks
  • 🥇 Gouden plaquette: Perfect Game onder 90 seconden
  • 🥈 Zilveren plaquette: Perfect Game onder 120 seconden

Regelbreker

RULE BREAKER: zet je het gedeelde woord in elke gok als laatste, dan eindig je op -100. Alles wordt weggeveegd, inclusief je reeksbonus.
